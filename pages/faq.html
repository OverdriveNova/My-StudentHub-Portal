General Questions

Q1: What is the primary purpose of StudentHub?

StudentHub is an academic portal designed for CHARUSAT DEPSTAR students enrolled in Web Development Frameworks (ITUE203). It allows students to manage profiles, view course tables, and register for campus events.

Q2: Which web browsers support StudentHub?

StudentHub uses standard HTML5 markup elements and works across all modern web browsers including:

  • Google Chrome (Latest)
  • Mozilla Firefox
  • Microsoft Edge
  • Apple Safari

Registration & Account Login

Q3: How do I complete the Student Registration process?

Follow these numbered steps to register a new account:

  1. Navigate to the Student Registration Form page.
  2. Fill in mandatory fields marked with an asterisk (*):
    • Full Name, Email Address, Phone Number
    • Password & Confirm Password
    • Department & Current Semester
  3. Upload your Student ID Card proof file (PDF, PNG, or JPG format).
  4. Check the declaration box and click Submit Registration.

Q4: What should I do if I forget my account password?

You can reset your password or contact the system administrator by submitting an inquiry on the Contact Support Page.

Campus Events FAQ

Q5: How do I register for the Web Innovation Hackathon?

Visit the Campus Events Page, locate the Web Innovation Hackathon event article, review the schedule table, and click the registration button.
