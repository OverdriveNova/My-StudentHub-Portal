About StudentHub Portal

CHARUSAT DEPSTAR • Institutional Overview

Portal Vision & Purpose

The StudentHub platform is designed specifically for students enrolled in the Web Development Frameworks (ITUE203) course during the 3rd semester (2026-27 ODD term).

Core Objective: To deliver a unified, accessible campus platform supporting student academic scheduling, course curriculum tracking, and centralized university resources.

Course Learning Roadmap

Course Curriculum Modules

  1. HTML Basics & Document Structure
    • Doctype, HTML root, Head, Title, Meta elements
    • Structural elements (<hr>, <br>, <img>, <input>)
  2. Semantic Text Elements & Formatting
    • Headings (<h1> to <h6>), Paragraphs, Formatting tags
    • Bold, Strong, Italic, Emphasis, Underline, Mark, Ins, Del, Sub, Sup
  3. Links, Media & Lists
    • Hyperlinks, Navigation architecture, and Web Security protocols
    • Unordered, Ordered, and Nested list structures
  4. Data Tables & Input Forms
    • Table rows, headers, cells, captions, colspan, rowspan
    • Form inputs, validation attributes, dropdowns, buttons

Academic Development Milestones

  1. Final Deployment & Review
  2. Backend Connection & Data Integration
  3. UI Layout Structuring
  4. Requirement Analysis & Wireframing
